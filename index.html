Connect JSONBin

Data lives in a private bin on jsonbin.io. Create a free account, copy your API key, then connect. Leave Bin ID empty to create a new bin.

JSONBin is already set from environment variables on this deploy.

On Render, set JSONBIN_API_KEY and JSONBIN_BIN_ID. Locally, the key stays in this browser and is sent only to jsonbin.io.
